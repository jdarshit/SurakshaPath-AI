# Screenshot Placeholders

|---|---|---|
| Splash Screen | `splash-screen.png` | Brand reveal and startup sequence |
| Hero Dashboard | `hero-dashboard.png` | Landing page and primary CTAs |
| Safe Route Comparison | `safe-route-comparison.png` | Explainable route selection view |
| Heatmap View | `heatmap-view.png` | Safety hotspot visualization |

| Admin Dashboard | `admin-dashboard.png` | Admin analytics and metrics |

## Notes

- Keep screenshots clean and high resolution.
- Prefer browser captures with the full UI visible.
- Use the same visual theme across all images for a polished portfolio look.
