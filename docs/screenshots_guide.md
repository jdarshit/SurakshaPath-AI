## Browser Layout Recommendations

### Recommended Zoom

- Use **90% browser zoom** for most desktop screenshots.
- Use **100% zoom** only for detailed dashboard captures where text clarity matters.
- Avoid zoom levels below 80% because UI labels may become too small.

### Recommended Viewport

- Desktop width: **1440 px** or **1600 px**
- Desktop height: **900 px** or taller
- Keep the browser maximized with no extra toolbars visible if possible.

### Layout Tips

- Capture the app with a clean, uncluttered browser window.
- Use a single consistent theme across all screenshots.
- Prefer screenshots with the hero and map visible at the same time when possible.
- For the admin dashboard, make sure charts and KPI cards are fully visible.
- For live navigation, let the route progress and alert panel be visible together.

## Presentation Quality Rules

- Use the same browser size for every screenshot.
- Keep the interface in dark premium mode for visual consistency.
- Wait for motion transitions to settle before capturing.
- Do not capture loading spinners unless that is the intended screenshot.
- Ensure the screenshots show real product value, not empty UI states.
